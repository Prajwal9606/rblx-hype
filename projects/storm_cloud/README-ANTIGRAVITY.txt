BLOCKY 3D STORY VIDEO - Antigravity version
===========================================

Install (pick one):
  Global (all projects):   copy the folder  blocky-3d-story-video  to   ~/.gemini/config/skills/
                           (older builds: ~/.gemini/antigravity/skills/)
  This workspace only:     copy it to   <your-project>/.agents/skills/
                           (older builds: <your-project>/.agent/skills/)

The CLI: run  /skills reload  after copying.
Then, in an EMPTY folder opened in Antigravity, say:  make a blocky story video
(or invoke it with  /blocky-3d-story-video ).
The first run creates a "studio" folder and installs everything; let it finish.

Needs: Node.js 18+, Python 3.10+, ~2 GB free disk, internet for first setup.
Optional: copy extra-sounds/*.wav into the studio's sfx/ folder.
